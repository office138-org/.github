# office138-org GitHub Standards

Organization-level community health and onboarding standards for AI-assisted development.

## Shared defaults

- `PULL_REQUEST_TEMPLATE.md` — default PR structure and Governance v1 checklist.
- `.github/ISSUE_TEMPLATE/general.md` — default general issue template.
- `CONTRIBUTING.md` — organization contribution lifecycle.
- `SECURITY.md` — security reporting and repository-safety baseline.
- `GITHUB_GOVERNANCE_V1.md` — organization GitHub lifecycle standard.
- `workflow-templates/` — discoverable starter workflow for repositories not created from the standard repository template.

Product repositories retain authority over product/runtime specifications and repository-specific governance. Shared CI execution is centralized in `office138-org/ci-standards`.
