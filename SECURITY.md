# Security Policy

## Reporting

Do not disclose secrets, credentials, private runtime evidence, customer data, or sensitive operational details in public issues or pull requests.

Report suspected security issues privately to the repository/organization owner with the minimum evidence required to reproduce the issue.

## Baseline

Repositories adopting GitHub Governance v1 must retain repository-safety checks for common sensitive paths and must not weaken or bypass those checks to obtain a green CI result.

Security-related changes still require a pull request, CI, and Human Approval unless an emergency process has been explicitly authorized and documented.
